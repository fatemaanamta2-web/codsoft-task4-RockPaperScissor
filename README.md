# Rock Paper Scissors Game

A simple command-line Rock Paper Scissors game developed using Python as part of my CodSoft Python Programming Internship.

## Features

- User can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Determines the winner based on game rules
- Displays user's and computer's choices
- Tracks scores for multiple rounds
- Allows the user to play again
- Provides clear instructions and feedback

## Game Rules

- Rock beats Scissors
- Scissors beat Paper
- Paper beats Rock
- Same choices result in a Tie

## Technologies Used

- Python
- VS Code

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `task4.py`.
4. Choose Rock, Paper, or Scissors.
5. View the result and score.
6. Choose whether to play another round.
